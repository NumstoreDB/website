## Conventions

- Code blocks render in monospace. Inline `code` is highlighted in amber.
- File paths use a leading slash when they refer to the repository root, e.g. `/src/store/wal.zig`.
- Where exact numbers matter, we cite them. Where they don't, we round.

Need something we haven't documented? Open an issue, or [contact us](https://numstore.com/contact).
