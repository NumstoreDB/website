# Numstore

A numerical storage engine purpose-built for scientific and analytical workloads.

This site collects everything you need to learn, install, operate, and follow along with the project:

- **[Documentation](/docs/)** — guides, reference, operations.
- **[Blog](/blog/)** — release notes, deep dives, postmortems.

If you are completely new, start with **[Getting Started](/docs/getting-started/)**.

---

## What is Numstore?

Numstore is built around three layered products:

1. **SmartFiles** — the on-disk numerical file format.
2. **Numstore** — the open-source storage engine.
3. **Numstore Enterprise** — the managed, supported, multi-tenant tier.

Read the [architecture overview](/docs/smartfiles/) to see how they fit together.
